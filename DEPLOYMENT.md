# Website preview setup

The site is a static HTML website. The homepage must be committed at the repository root as `index.html`.

## First upload

1. Download and extract the latest Sophie Graham Hair website ZIP from the ChatGPT conversation.
2. On GitHub, open the repository, choose **Add file → Upload files**.
3. Drag `index.html`, `salon-interior.jpg`, and `salon-exterior.jpg` into the upload area (keep them at repository root).
4. Commit directly to `main`.

## Publish preview

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Once deployed, the preview will be available at https://maxdonaghey.github.io/Sophie_Graham_Hair/ .

## Notes

- This repository is public: obtain the salon's permission to reuse images and branding before public publishing.
- Never publish secrets, passwords or customer information.
- Publishing this preview does not change the salon's existing website.
